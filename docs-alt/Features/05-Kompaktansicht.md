# Kompaktansicht

## Status

Die Kompaktansicht ist als eigenständiges späteres Feature vorgesehen. Ihr
konkreter Inhalt und ihre Bedienung werden vor der technischen Umsetzung
gesondert fachlich festgelegt.

Die im Altsystem als „Druckvorschau“ bezeichnete verkürzte Bildschirmtabelle
dient dafür als Analysegrundlage, wird aber nicht unter dieser irreführenden
Bezeichnung übernommen.

## Abgrenzung zur Planungsseite

- Die Kompaktansicht gehört nicht zum aktuellen Umsetzungsschritt der
  [Planungsseite](./03-PlanPage.md).
- Bis zur Umsetzung erscheint auf der Planungsseite weder eine Umschaltung noch
  ein Platzhalter für sie.
- Sie ist keine echte Druckvorschau.
- Druck und PDF-Export werden unabhängig davon zum Ende der Umsetzung
  behandelt.
- Fachliche Festlegungen zum konkreten Tabelleninhalt werden in diesem Dokument
  erst ergänzt, wenn die Arbeit am Feature beginnt.
