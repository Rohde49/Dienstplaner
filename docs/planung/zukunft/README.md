# Zukunftsvorhaben

Dieser Ordner enthält bereits konkretisierte Vorhaben, deren Umsetzung bewusst
auf einen späteren Zeitpunkt verschoben wurde. Die Ablage hier bedeutet weder,
dass das Vorhaben verworfen ist, noch dass bereits ein Umsetzungstermin
feststeht.

Die [Roadmap](../roadmap.md) bleibt die einzige Quelle für aktuelle
Prioritäten und Reihenfolgen. Voraussetzungen, die ein Zukunftsplan für eine
bestimmte Auslieferungsart nennt, gelten unabhängig von seiner zeitlichen
Einordnung weiterhin.

Jeder Zukunftsplan nennt in seinem Statusabschnitt mindestens:

- den Status `Zukunftsvorhaben`,
- den verlässlich belegbaren Erstellungs- oder Einordnungszeitpunkt,
- die zugehörige Zeitzone und gegebenenfalls den dokumentierenden Commit sowie
- ob bereits ein Umsetzungstermin festgelegt wurde.
